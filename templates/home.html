How agents discover this

Agents find WeatherAgent through the NAIS standard — DNS-based discovery, no registry needed.

1

DNS Lookup

Query _agent.weatheragent.nais.id for the TXT record containing manifest and MCP URLs.

2

Fetch Manifest

GET /.well-known/agent.json for capabilities, auth methods, and payment info.

3

Resolve via NAIS

Use resolver.nais.id or any NAIS SDK to validate and resolve the agent in one call.

4

Call MCP Endpoint

POST JSON-RPC 2.0 requests to /mcp to invoke tools. No API key required.
